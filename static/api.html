协议、隐私与费用提示

此页使用 OpenAI 兼容的 multipart/form-data 音频转录协议。需要服务支持 audio/transcriptions；模型名称、文件大小、音频格式及字幕时间轴支持以服务商为准，不保证兼容所有第三方 API。

仅在首页明确选择第三方 API 并确认任务后，抽取的音频及提示词才会发送到所配置的服务，可能产生费用；不发送原视频或源文件路径。HTTP 代理启用后也参与传输，本地转录流程不变。

音频按最多 10 分钟、单声道 MP3 分块上传。SRT/VTT 需要服务返回完整有效的分段时间轴；否则任务失败，可改用 TXT。取消只能停止本机请求，不能撤回已上传音频或费用；中断的 API 任务不会自动重新上传。

「确定」只保存并应用配置，不会调用第三方服务，也不代表认证、代理或连通性测试成功。
